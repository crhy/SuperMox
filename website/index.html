Discover the Spaced Linux Desktop.

Spaced Linux shares SuperMox’s commitment to open computing and user control. Built on Devuan with sysvinit, it brings together the familiar MATE desktop, Compiz window management, and a choice of coordinated themes. Free and open source, with no systemd dependency and no account required.

Explore a desktop you can use today while SuperMox’s wider cross-device vision develops.

IN DEVELOPMENT

SuperMox is being built piece by piece. The full cross-device experience described here is the project’s vision, not a finished universal OS.

  1. 01

    Establish the open foundation

    A Devuan-based platform with Proxmox-derived virtualization and clustering. Build automation and virtual machine testing.

    FOUNDATION
  2. 02

    Unify the experience

    A LineageOS-based interface, cluster resource management, and simple onboarding for supported devices.

    PLANNED
  3. 03

    Bring the personal cloud to life

    Distributed, prioritized storage, with the whitepaper’s proposed authentication, encryption, and recovery model.

    PLANNED
  4. 04

    Open the network

    Optional resource sharing with friends and family, reciprocal backups, and a proposed marketplace for idle computing power.

    LONG-TERM VISION

A FEW GOOD QUESTIONS
Can I install SuperMox on all my devices today?+

Not yet. SuperMox is in development. Universal device support, shared resources, and the personal cloud are the intended direction. Visit GitHub for the current project materials and development information.

What happens to my existing apps and hardware?+

The whitepaper calls for a familiar Android-like experience and a longer useful life for existing hardware. Supported devices, application compatibility, and migration paths will need to be established as the platform develops.

How does the whitepaper approach privacy?+

It proposes keeping data on user-controlled devices, distributed backups, hardware biometrics, encryption, recovery phrases, and onion-routed traffic. These are design proposals; implementation and security validation remain part of the work ahead.

How can I contribute?+

Read the whitepaper and repository, open an issue with a concrete idea, or join the discussion about architecture, user experience, hardware support, and testing. The project’s aim is an open platform shaped by its users.
